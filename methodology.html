ICO Data Protection Decisions Database: sources & methodology

This page explains how Rowcraft compiled its database from the ICO’s published data-protection complaint and case CSVs. “ICO Data Protection Decisions Database” is the product name for this independent compilation; it is not an official ICO product.

Important context

These are published complaint-case records; they do not all represent enforcement actions or findings against the named organisations. A complaint, its outcome or an organisation’s complaint count is not, by itself, proof of wrongdoing or a measure of compliance. Rowcraft is not affiliated with, endorsed by or acting on behalf of the ICO.

How the database was prepared

  1. Combined eight source CSVs. The source files use different headings and date formats; their records are mapped to a consistent set of columns.
  2. Standardised values. Leading and trailing whitespace is trimmed and dates are parsed to ISO format (YYYY-MM-DD). The source file name is retained for traceability.
  3. Removed duplicate case references. One row is retained for each unique ICO case reference.
  4. Added a calculated duration. days_to_close is calculated as the number of days between the received and completed dates.
  5. Added a practical outcome label. The outcome field groups the ICO’s source detail1 field as shown below. The original decision-detail fields remain in the CSV.
  6. Removed internal search helpers. Search-only fields used by the explorer are not included in the download.
